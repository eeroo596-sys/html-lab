Миний тухай

Нэр:А.Эрхэмбилэг
Сургууль:Мэдээллийн системийн 2-р курсийн оюутан
Мэргэжил:Мэдээллийн систем

Мэдээллийн систем мэргэжлийн тухай

Мэдээллийн систем нь бизнес, байгууллагын хэрэгцээг мэдээллийн технологитой холбож, өгөгдлийг цуглуулах, хадгалах, боловсруулах, шийдвэр гаргахад ашиглах системийг бүтээх мэргэжил юм.

Суралцах гол чиглэлүүд:

  • Програмчлал, вэб хөгжүүлэлт
  • Өгөгдлийн сан, өгөгдлийн шинжилгээ
  • Системийн шинжилгээ, зохиомж
  • Сүлжээ ба мэдээллийн аюулгүй байдал
  • Төслийн менежмент

Мэдээллийн системийн мэргэжилтэн юу хийдэг вэ?

Мэдээллийн системийн мэргэжилтэн нь байгууллагын мэдээллийн системийг төлөвлөж, хөгжүүлж, нэвтрүүлж, дэмжин ажиллуулдаг.

  • Хэрэглэгчийн шаардлагыг судалж, системийн шинжилгээ хийнэ
  • Програм хангамж, вэб болон мобайл аппликейшн хөгжүүлнэ
  • Өгөгдлийн сан зохиомжилж, удирдаж, нөөцлөнө
  • Системийн алдааг засаж, шинэчлэлт хийнэ
  • Мэдээллийн аюулгүй байдлыг хангана
  • Тайлан, шинжилгээгээр удирдлагад шийдвэр гаргахад тусална

Flexbox ба Grid layout

Flexbox нь элементүүдийг нэг чиглэлд (мөр эсвэл багана) жигд байрлуулахад, CSS Grid нь мөр болон баганаар хос чиглэлтэй сүлжээ үүсгэхэд тохиромжтой. Энэ лабораторийн хуудсанд хоёуланг нь хэрэглэж болно.
