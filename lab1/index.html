Миний тухай

Суралцах хугацаандаа мэдээллийн системийн талаар илүү их мэдлэг эзэмшиж, програмчлалын чадвараа хөгжүүлэхийг зорьж байна. Шинэ зүйл сурч, өөрийн мэдлэгээ практикт ашиглах сонирхолтой.

Сонирхол

  • Мэдээллийн систем
  • Програмчлал
  • Өгөгдлийн сангийн систем
  • Өгөгдлийн бүтэц
  • Алгоритм
  • Шинэ технологиуд

Сурч байгаа зүйлс

  • Java програмчлал
  • Өгөгдлийн бүтэц ба алгоритм
  • Өгөгдлийн сангийн систем
  • Мэдээллийн системийн үндэс
  • Вэб зохиомжийн үндэс

Миний зорилго

Мэдээллийн системийн чиглэлээр мэдлэг, ур чадвараа хөгжүүлж, цаашдаа мэргэжлээрээ ажиллахад шаардлагатай туршлага хуримтлуулах зорилготой.
